# Registre des Décisions d'Architecture (ADR)

Ce répertoire consigne l'ensemble des décisions architecturales structurantes adoptées au cours du développement du **Laravel Plugin-First CMS**.

Chaque décision suit le format standard :
- **Titre & Numéro**
- **Date & Statut**
- **Contexte & Problématique**
- **Décision adoptée**
- **Conséquences positives et négatives**
- **Alternatives écartées**
